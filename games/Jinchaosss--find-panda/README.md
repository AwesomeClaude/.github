## Play

- Open the project in Cocos Creator 4 (3.8.8 per package.json) and build with \`cocos build --project . --platform web-mobile\`, then open the web-mobile build in a browser.
- From the menu (找熊猫 / Find the Panda), tap 开始游戏 to open the 12-level select grid (5x5 up to 8x8).
- Tap a grid cell to cycle its state: empty → grass → panda (bamboo cells are fixed and cannot change).
- Drag across cells to quickly mark grass.
- Satisfy all rules: each bamboo must be orthogonally adjacent to exactly one panda, each panda pairs with exactly one bamboo, pandas never touch even diagonally, and every row/column count must match its hint number.
- Use the hint button when stuck (it has a cooldown); wrong placements cost one of 3 lives — lose all 3 and the level is failed, solve the grid to clear the level.

## Mechanics

- Grid deduction placement: cycle cells between empty, grass marker, and panda next to fixed bamboo cells
- Orthogonal bamboo-panda pairing constraint (exactly one panda per bamboo and vice versa)
- Panda non-adjacency constraint including diagonals
- Row and column panda-count hints that must all match
- 12 precomputed levels from 5x5 to 8x8, generated by tools/generate-levels.js with backtracking uniqueness verification
- Tap-to-cycle plus drag-to-mark-grass touch input on a portrait web-mobile layout
- Menu, level-select, playing, win, and lose screens with cleared-level tracking
- Hint button with cooldown and a 3-lives failure system
